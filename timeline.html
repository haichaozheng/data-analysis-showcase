项目之旅

17 周 · 4 个阶段 · 从真实问题到公开路演

1
Idea Stage · 发现问题 W1 – W3

核心挑战：如何发现财经领域的真实问题并定义一个有价值的项目？

  • W1 课程启动：组建互助小组，搭建 AI 辅助编程环境，完成并提交社区调研（≥3 条原话）
  • W2 数据全景与 opencode：用 opencode 分析公约问卷并更新课程网站，数据生态概览与财经新闻导入，生成采集脚本拉取西财要闻，延续社区倾听补原话
  • W3 建仓与提案：初始化个人项目仓库 + AGENTS.md + docs/ 五件骨架与 .venv 虚拟环境，社区互查，采集代码精讲，用户访谈，提交个人项目提案
2
MVP Stage · 构建产品 W4 – W10

核心挑战：如何把一个想法变成可运行的数据分析产品？

  • W4 手动流程先行 + 项目数据获取与落盘 + 批判性思维与判断：获取并落盘项目数据（API/网页采集+合规自检），手动完成一次完整分析，先验证价值再自动化
  • W5 数据清洗与探索 + Prompt驱动EDA：Pandas 清洗与 EDA，用 opencode 将 W4 手动流程转化为代码并验证一致性，Prompt 生成 ≥3 条洞察
  • W6 NumPy/Pandas 进阶与 Matplotlib 静态可视化（工具基础周）：NumPy 基础、groupby 聚合与 pandas.plot 静态图（每图配一句"回答什么问题"）；课后自学 DeepSeek API 接入
  • W7 产品原型搭建 + AI辅助编程加速原型 MVP v0.1：将 EDA 与静态图迁移进 Streamlit 产品框架，接入 DeepSeek API；课后提交选题报告 v2
  • W8 可视化设计 + 文本分析入门（弹性缓冲周）：好图/坏图对照与叙事序列，分词 vs 大模型 tokenization，情感分析，Plotly/Pyecharts 交互图
  • W9 LLM 原理与 OpenCode Skills 开发 + 同侪互评 + 开始打磨 v0.2：LLM 原理回顾，OpenCode Skill 开发实践（≥1 个 SKILL.md），组内 MVP 互评定向迭代
  • W10 打磨迭代 + 上线部署 公网上线 v0.3：打磨可演示版，部署到 Streamlit Cloud（当堂人人出 URL），撰写部署方案，DSR 自检写入 journal.md
3
Launch Stage · 上线迭代 W11 – W15

核心挑战：如何让产品上线、找到用户、持续改进？

  • W11 机器学习建模基础：训练/测试划分直觉、梯度下降、线性回归；部署验收为课后事项，部署成功当天即开始用户触达（滚动至 W14）
  • W12 KNN + 特征工程 模型 v0.1：KNN 分类与特征工程，朴素贝叶斯自学，获客渠道复盘与深化（目标 W14 收口 5-10 条反馈）
  • W13 决策树与随机森林 模型 v0.2：决策树分裂直觉，随机森林 bagging + 随机特征，特征重要性反哺特征工程，三模型思路对比
  • W14 量化交易基础：从SMA到ML信号 + 策略回测评估 模型 v0.3：SMA 策略回测入门，ML 信号生成，策略评估（夏普比率/最大回撤/胜率），与 SMA 基线或买入持有对比
  • W15 多模型信号融合 + 路演准备 产品 v1.0：多模型投票/加权融合与回测对比，课程路径总结，路演 PPT 大纲 + Demo 脚本
4
Scale Stage · 展示反思 W16 – W17

核心挑战：如何展示成果、反思收获、提炼可迁移的知识？

  • W16 公开路演：产品须公网可访问，现场其他人当场打开试用，面向全校与企业合作伙伴；兜底切录屏 Demo
  • W17 反思与展望：最终反思报告，个人知识框架重构，产品下一步思考
