# 数据分析与可视化 — 学生项目展示

2026秋季课程学生项目展示网站。

## 项目信息

- **课程**：数据分析与可视化
- **学期**：2026秋季
- **教学方法**：PBL（Project Based Learning）

## 如何更新项目

1. 编辑 `index.html` 文件
2. 在 `<div class="projects">` 区域添加项目卡片
3. 提交并推送到 GitHub

## 项目卡片格式

```html
<div class="project">
    <div class="project-header">
        <div class="project-title">项目名称</div>
        <span class="project-status status-progress">进行中</span>
    </div>
    <div class="project-student">学生姓名 · 专业年级</div>
    <div class="project-desc">项目简介</div>
    <div class="project-links">
        <a href="#">产品链接</a>
        <a href="#">项目仓库</a>
    </div>
</div>
```

## 状态样式

- `status-progress`：进行中（黄色）
- `status-launch`：已上线（蓝色）
- `status-done`：已完成（绿色）
