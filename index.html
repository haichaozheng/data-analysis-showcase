课程简介

本课程旨在培养学生数据分析与可视化能力，通过实际项目实践，让学生掌握数据收集、清洗、分析和可视化呈现的全流程技能。课程涵盖 Python 数据分析、SQL 数据库操作、数据可视化工具等内容，注重理论与实践相结合。

课程公约

1. 诚信原则：独立完成作业，禁止抄袭代码，引用需注明来源。

2. 团队协作：小组项目需明确分工，定期沟通，共同推进。

3. 代码规范：遵循项目代码规范，添加必要注释，保持代码可读性。

4. 及时提交：按时提交作业，如有困难提前沟通。
